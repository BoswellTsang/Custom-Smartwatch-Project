# Custom Smartwatch - Optical AFE PCB Board

**Status** In Progress

# Overview
This is a separate PCB board housing the optical AFE components needed for heart rate sensing. This board will connect to the main board through a surface mounted connector.

The entire board is 8.4 mm in radius.

# Component Selection:

| Subsystem | Selected hardware / design |
| --- | --- |
| Secondary regulator | TI TPS7A2018PDBVR LDO; target 1.8 V |
| Ambient light | TI OPT3004, I²C |
| Optical sensing | MAX86141ENP+T AFE |
