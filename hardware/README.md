# Hardware design sources

Planned structure:

- `hardware/kicad/main-board/`: native main smartwatch KiCad project (not uploaded yet).
- `hardware/kicad/optical-sensor/`: separate MAX86141 optical AFE KiCad project (not uploaded yet).
- `hardware/fabrication/`: manufacturing revisions, BOMs, Gerbers, drill/placement files once finalized.

Commit native `.kicad_pro`, `.kicad_sch` and `.kicad_pcb` files as well as required custom symbols/footprints. Keep KiCad local and backup files out of version control.

**Current GitHub contents document the design; the original KiCad files have not been uploaded.**
